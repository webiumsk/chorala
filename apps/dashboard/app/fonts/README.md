# Vendored dashboard fonts

The dashboard uses the same Hanken Grotesk and Fraunces typefaces as upstream,
served locally through `next/font/local`. No Google Fonts request is required
at build time or in the browser. Font files are unchanged variable TrueType
artifacts from the official [Google Fonts repository](https://github.com/google/fonts)
at revision `e7db6ca603fd4862010383ff17ffd6cc4ffac1c0`, retrieved 2026-10-25.

Hanken Grotesk provides the normal sans face. Fraunces provides normal and italic
display faces. Existing CSS variable names and selected weight ranges remain
unchanged. Both families use the SIL Open Font License 1.1; their complete original
notices are retained alongside these files. License copies normalize trailing
whitespace only; their wording is unchanged. The hashes below describe the local
artifacts.
